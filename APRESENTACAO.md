# Apresentacao profissional

## Identidade e valor

Este projeto implementa recuperacao de imagens por conteudo para acervos de arte. A cadeia verificavel vai da coleta de metadados e imagens a embeddings EfficientNetB0, indexacao vetorial no Qdrant, metadados em MySQL, objetos no MinIO e exposicao de busca por Flask.

Ele e relevante para museus, acervos digitais, humanidades digitais e experiencias de recomendacao visual.

## Texto para publicacao

> Desenvolvi este experimento de busca visual para investigar como acervos de arte podem ser explorados pela semelhanca entre imagens, e nao apenas por campos textuais. A solucao integra coleta de dados, embeddings com EfficientNetB0, busca vetorial no Qdrant, metadados relacionais e armazenamento de objetos. O desafio foi conectar essas camadas de forma que uma consulta visual retornasse resultados interpretaveis e associados aos seus metadados. O projeto registra uma base tecnica para aplicacoes de descoberta e recomendacao em colecoes culturais.

## Evidencias visuais recomendadas

1. Grade de resultados de busca por imagem com escores.
2. Resposta da API contendo metadados e referencias de imagem.
3. Etapas de indexacao e colecao vetorial.
4. Fluxo entre MySQL, Qdrant e MinIO.
